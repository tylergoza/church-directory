How households are made

  • Rows with the same household name share one household.
  • With no household name, rows with the same address share one. Anyone else gets a household of their own.
  • A household with several different addresses gets all of them, and each person is at the address on their own row.
  • Names are matched against people already here and against earlier rows, with the same rule as everywhere else: last name, first name or goes-by, and the same suffix. For each row you choose to add it, skip it, or use the person already here (they move into the household the row describes, or are left alone if the row has no household or address).
  • Dates with slashes are month first (3/14/1980).
